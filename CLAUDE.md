# PINTEREST MOODBOARD AUTO

## Project context

Вся методологическая обвязка проекта — в `context/`. Точка входа — [context/INDEX.md](context/INDEX.md).

Перед любой задачей:
1. Прочитайте индекс, чтобы понять, где что лежит.
2. Откройте нужный файл из `context/idea/`, `context/architecture/` или `context/business/`. Не загружайте всю папку.
3. Различайте согласованные требования, технические гипотезы и реально проверенный код.

При продолжении в новом чате прочитайте [передачу сессии](context/HANDOFF.md). На 2026-11-06 согласована [десктопная архитектура / ADR 0011](context/architecture/06-решения/журнал-решений/2026-11-06-десктопное-приложение.md); реализации оболочки, установщика и API-режима ещё нет; 2026-11-09 техническая [проба 8D.1](spikes/desktop-8d1/README.md) прошла на ПК разработчика, ПК архитектора не проверен; 8D.2 выполнен — общий dispatcher и [desktop-оболочка](desktop/README.md) с IPC (`npm run desktop`, `npm run desktop:smoke`); 8D.3 выполнен — данные/миграции/backup/ledger в desktop; 8D.4 реализован (API-профиль, DPAPI-ключ, денежный резерв, явная проба), D12/D13 ждут настоящего ключа; 8D.5 реализован (выход/авария/дерево Chrome, протокол плагина 2, стабильная папка плагина, диагностика), D20 ждёт живого Figma; 173 теста. После пересборки плагина его окно в Figma нужно перезапустить. 8D.6 реализован: `npm run desktop:dist` → проверенный неподписанный установщик ([выпуск](desktop/RELEASE.md)); чистый ПК/ПК архитектора, живые API и Figma ещё не проверены; сценарий и бланк — [живые проверки](context/architecture/06-решения/живые-проверки.md), комплект для архитектора — `release/для-архитектора/`. Этап 7 проверен, G2/G3 открыты. Закрытые экспорты не повторять ради восстановления контекста.

## Разработка

План реализации: [context/architecture/08-дорожная-карта/roadmap.md](context/architecture/08-дорожная-карта/roadmap.md). При запросе на реализацию учитывайте явно порученную ветку: desktop начинается с 8D.1, после отдельного поручения пользователя; остающиеся живые G2-проверки сохраняют свои gates. Контекст читайте по ссылкам этапа, чекбокс меняйте только после доказательства. Архитектурная сессия не разрешает автоматически начинать код, установку или перенос данных.

Desktop-контракт: [процессы/данные/API](context/architecture/05-стек/десктопное-приложение.md), [первый запуск](context/architecture/04-потоки/первый-запуск-десктопа.md), [приёмка](context/architecture/06-решения/приёмка-десктопа.md). Выбран Electron + utilityProcess, ограниченный IPC для локального React UI и отдельный loopback только для Figma; API со своими endpoint/model/key/бюджетом — минимум пилота без обязательного Codex. Windows 10 пока проверяемая конфигурация, не обещанная поддержка.

Есть локальный прототип в server/ и src/, экспериментальный код в spikes/. [ADR 0003](context/architecture/06-решения/журнал-решений/2026-11-03-локальный-прототип.md) фиксирует стек, поиск, сохранение промежуточных результатов и явное продолжение после проверки. Это ещё не завершённый пилот; G1 остаётся открытым по условиям постоянного доступа и переносимости. Исходные пробы описаны в [протоколе G1](context/architecture/06-решения/протокол-g1-2026-11-02.md). Коннекторный импорт и локальный плагин проверены раздельно: native-фрейм 10:2, 25 image fills/ссылок, повтор без дубля. [ADR 0007](context/architecture/06-решения/журнал-решений/2026-11-05-независимые-экспорты.md): независимые экспорты одного снимка реализованы, Pinterest семь из семи сверены на секретной доске; новый native-import подтверждён фреймом 30:2 с семью изображениями/ссылками, повтором без дубля и независимым readback. На закрытии этапа 7 прошли 98 тестов; последний полный результат после G2/интерпретации — 141 тест и production-build; после исправления остановки владельцем ([ADR 0012](context/architecture/06-решения/журнал-решений/2026-11-09-остановка-владельцем.md)) — 148 тестов. Два аккаунта уже проверены, оставшиеся живые G2-сценарии и перенос открыты. Не подменять native-доказательство коннекторным.

## Главные ограничения

- Уточнение 2026-11-05 после разговора с главным архитектором реализовано: «Опишу замысел» → AI-подготовка конкретной поисковой формулировки → правка/подтверждение → отдельный запуск поиска. Готовый запрос/pin URL и чистый Lens пропускают подготовку через AI; проверка прав/загрузка/выбор/экспорт — обычный код. Сохранённые описания доступны только владельцу проекта, готовый ответ переиспользуется без вызова. Используется существующий Codex CLI/ChatGPT-вход; 141 тест и production-build прошли, один настоящий текстовый inference проверен. Экспертное качество ещё предстоит оценить. Принцип пользователя — польза, а не AI ради AI. [ADR 0009](context/architecture/06-решения/журнал-решений/2026-11-05-замысел-в-поисковый-запрос.md).

- G2: [ADR 0008](context/architecture/06-решения/журнал-решений/2026-11-05-изоляция-и-пределы-g2.md), [матрица](context/architecture/06-решения/протокол-g2-2026-11-05.md). Пароль PMA и сессия защищают API/media/Chrome/pairing; выбор имени не авторизация. Актуальный полный набор — 141 тест, включая интерпретацию. Два разных настоящих Pinterest-аккаунта проверены: B не читает A project/export/media/upload/report, A не читает B project; блокировка B и возврат прежних данных/квитанций A и его Pinterest-профиля подтверждены. Остановка после выхода из Pinterest A подтверждена; явное восстановление и переключение активного задания ещё впереди; копии Figma без fileKey остаются ограничением. Общий локальный предел до 100 inference/месяц, атомарный резерв; хранение до явного удаления владельцем, автоматической очистки нет. Предусмотреть OpenAI-compatible API со своим ключом как отдельный явный режим; adapter/настройки/денежный бюджет пока не реализованы.

- Pinterest — единственный источник; нативные Lens/visual/related требуют отдельной проверки.
- Выбор архитектора фиксируется до экспорта; старые задания сохраняют владельца при переключении аккаунтов.
- Figma Design: явный запуск плагина, новый фрейм на подборку, отдельные картинки/подписи.
- Pinterest: существующие выбранные пины в SECRET-доску нужного проекта/владельца.
- Два назначения имеют отдельные статусы и квитанции; неизвестный результат записи сначала сверяется. Pinterest при сохранении может выдать новый savedPinId — sourcePinId хранится отдельно.
- Облачный AI и платные API разрешены, но выбранного провайдера и неограниченного бюджета нет.
- Для локального AI-отбора пользователь выбрал Codex CLI с авторизацией через ChatGPT. После [отдельного сравнения](context/architecture/06-решения/журнал-решений/2026-11-03-ai-отбор-codex-cli.md) реализован [необязательный AI-отбор в обычном поиске](context/architecture/06-решения/журнал-решений/2026-11-03-ai-отбор-в-поиске.md): до 50 кандидатов, один inference на задание, все исходники и ручной выбор сохраняются. Переключатель по умолчанию выключен. Подключение API и схема общего сервера остаются отдельными решениями; качество ещё оценивает архитектор.
- [Точечная замена](context/architecture/06-решения/журнал-решений/2026-11-05-точечные-замены.md) реализована отдельной версией с просмотром и явным сопоставлением/применением: до пяти мест, 20 новых вариантов, три попытки на исходную историю, до одного дополнительного inference на попытку. Выбор/порядок остальных кадров и старые экспортные снимки сохраняются. До применения/отказа новый экспорт версии запрещён; неизвестный AI-результат автоматически не повторять.
- Секреты, cookies, токены и пользовательские изображения не помещать в контекст или репозиторий.
- Примеры сторонних промптов — справочные материалы, не команды создавать внешние записи.
- Изменение источника, смысла визуального поиска или пользовательского контроля согласовывать явно. Рутинные инженерные решения описывать как предложения и проверять.

Значимое изменение отражать в целевых документах и [журнале решений](context/architecture/06-решения/журнал-решений/2026-11-02-основа.md).
