# PMA desktop (8D.2)

Electron-оболочка над тем же backend, что и веб-прототип. Контракт: [desktop-архитектура](../context/architecture/05-стек/десктопное-приложение.md), [ADR 0011](../context/architecture/06-решения/журнал-решений/2026-11-06-десктопное-приложение.md).

- `main.mjs`: окно `app://pma` (sandbox, contextIsolation, без nodeIntegration), single-instance, supervisor worker'а, выход по крестику с пределом 15 с. Проверяет отправителя IPC (только главный frame своего окна на `app://pma`), пропускает операции из allowlist. После lock или смены аккаунта закрывает отчёты, очищает кэш и перезагружает окно. Ссылки на пины открываются в браузере пользователя, отчёт AI — в отдельном окне без preload.
- `ipc-policy.mjs`: allowlist операций, строгие ID, тело — JSON-объект до 36 МБ, разбор `app://` (только UI из `dist/` и авторизуемые media/report), канонические ссылки на пины.
- `preload.cjs`: `window.pma = {version, api(method, route, body)}`, больше ничего.
- `worker.mjs`: utilityProcess со Store/jobs/Chrome. Запросы UI идут через `createIpcClient()` из `server/app.mjs` (тот же `dispatch`, что у HTTP). Loopback `127.0.0.1:8787` в desktop-режиме обслуживает только Figma (`figmaOnly`); если порт занят, Figma помечается недоступной, чужой процесс не трогается.

## Данные (8D.3)

Корень — `%LOCALAPPDATA%\PMA` (`server/data-root.mjs`). При старте worker: блокировка `instance.lock` (второй процесс получает отказ; после аварии ОС снимает её сама) → проверка версии `data/pma.sqlite` (более новую не трогает; старую — только после полного backup в `backups/<id>`) → Store → AI-ledger `accounting/ledger.sqlite` (если он пропал, подменён или старше проекта — платный AI закрыт) → recovery. Перед операциями записи нужно не меньше 300 МБ свободного места, иначе ответ 507; PMA ничего не удаляет сама.

Оператор при закрытой PMA:

```bash
node scripts/pma-data.mjs status
```

```bash
node scripts/pma-data.mjs restore <id>
```

Restore заменяет только проектную БД (после проверки SHA базы и файлов), отзывает коды Figma и не трогает ledger: расход не уменьшается, уже начатый AI-шаг не получает второй вызов.

## AI (8D.4)

«Настройки AI» (видны только в desktop): адрес HTTPS, формат Responses/Chat Completions, модель, изображения и их верхний предел токенов, предел вывода, тариф и валюта, денежный предел месяца, ≤100 вызовов. Сохранение ничего не вызывает. Ключ хранится в `%LOCALAPPDATA%\PMA\secrets` через Windows DPAPI (`safeStorage` в main); UI видит только последние 4 символа. Перед работой нужна «Платная проверка»: один запрос с картинкой 64×64 и строгой схемой; она же учитывается в бюджете. Каждый вызов заранее резервирует доказанную верхнюю стоимость в ledger и сверяется по usage; без usage, при превышении оценки или неизвестной части тарифа платный AI закрывается до новой проверки.

## Жизненный цикл и Figma (8D.5)

Крестик: новые операции получают 503, worker останавливает задачи (поиск → `interrupted`), Chrome и данные; через 15 с main завершает дерево worker (`taskkill /T`) и Chrome, запущенный с профилем из `%LOCALAPPDATA%\PMA\profiles` ([process-tree.mjs](process-tree.mjs)); другие `chrome.exe` не трогаются. Если worker умер — то же и выход; если умер main — уборка при следующем старте до открытия данных.

Плагин Figma копируется в `%LOCALAPPDATA%\PMA\integrations\figma-plugin` (путь не меняется при обновлениях). Плагин передаёт `?protocol=2`; другая версия получает 426 до чтения пакета. Если порт 8787 занят чужой программой, код Figma не показывается. «Состояние PMA» показывает версии, мост Figma, папку плагина с инструкцией импорта, состояние AI и создаёт безопасный отчёт только по кнопке.

## Запуск

```bash
npm run desktop
```

```bash
npm run desktop:smoke
```

`npm run desktop` собирает UI и запускает Electron с данными в `%LOCALAPPDATA%\PMA` (`data/`, `profiles/`, `shell/`). `npm run desktop:smoke` прогоняет 23 проверки (включая выход и аварии с настоящим Chrome PMA, без Pinterest) на временных искусственных данных в `%TEMP%`, без Pinterest/AI, с отдельным портом Figma. Переменные `PMA_DESKTOP_ROOT` и `PMA_FIGMA_PORT` нужны только для тестов.
