# Техническая проба Pinterest G1

Это ограниченный эксперимент, не готовое приложение бюро. Реальные результаты находятся в git-игнорируемом `output/playwright/g1/`; cookies и токены не извлекаются.

## Что сделано

Через вошедшую вручную сессию Playwright проверены текстовый поиск, related, visual search пина, Lens локального JPG и изменение области Lens. Собрано 29 уникальных текстовых кандидатов; первые 25 скачаны и отображены локально.

После явного выбора пользователя один существующий пин сохранён в новую private board; доска повторно открыта и проверена. Pinterest выдал сохранённому экземпляру другой ID: исходный и сохранённый идентификаторы хранятся раздельно.

## Файлы

- `extract-dom.mjs` — чистое чтение отрендеренных ссылок/картинок для `page.evaluate(extractPinCards)`.
- `pins.mjs` — нормализация, проверка источников, ID и одиночного save-readback.
- `download.mjs` — до 25 HTTPS-изображений i.pinimg.com, ограничения размера/времени, SHA-256 и checkpoint.
- `preview.mjs` — статическая галерея из локальных изображений и ссылок.
- `serve-preview.mjs` — loopback-only сервер; не отдаёт cookies, полный capture или приватные квитанции.
- `test/` — границы источников/медиа, большие ID, дедупликация, отсутствие секретных полей и source→saved mapping.

## Локальные команды

Из этой папки: `npm test`. Зависимости npm не требуются; используется Node.js 24.

Из корня проекта:

```powershell
node .\spikes\pinterest-g1\download.mjs .\output\playwright\g1\capture.json
node .\spikes\pinterest-g1\preview.mjs .\output\playwright\g1\capture.json
node .\spikes\pinterest-g1\serve-preview.mjs .\output\playwright\g1 8787
```

Галерея: http://127.0.0.1:8787/. В текущем сеансе уже запущена. Не запускать второй процесс на том же порту.

`capture.json` создавался из живых DOM-наблюдений инструмента Playwright; он не включён в репозиторий и не заменяется фиктивной выдачей. Полностью самостоятельный браузерный adapter ещё предстоит реализовать.

## Границы

Нет AI-отбора, семантической/перцептивной дедупликации, интерфейса пользовательского задания, многопользовательской авторизации и автоматического подтверждения выбора. Свежая browser-сессия требует ручного входа. Не используются stealth, обход CAPTCHA и недокументированные HTTP endpoints.

Сервер отдаёт также public-only пакет `/figma-package.json` для локального Figma-теста. Его CORS открыт только ради этих публичных технических изображений. Это не протокол будущего приватного приложения: перед клиентскими материалами нужны pairing и права.
