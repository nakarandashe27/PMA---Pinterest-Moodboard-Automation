# PINTEREST MOODBOARD AUTO

Внутренний инструмент ландшафтного бюро. Работает локальный прототип: свободное описание замысла → AI-подготовка поискового запроса → подтверждение, поиск Pinterest через отдельный профиль Chrome, необязательный AI-отбор, ручной выбор, точечные замены и независимые экспорты в Pinterest и Figma. Самостоятельный пилот и перенос на другой ПК ещё впереди.

## Десктопная версия — согласована, ещё не реализована

2026-11-06 принят [ADR 0011](context/architecture/06-решения/журнал-решений/2026-11-06-десктопное-приложение.md): Electron, отдельный backend, локальный UI через ограниченный IPC, установленный Chrome и готовый Figma-плагин. Для первого пилота — настраиваемый OpenAI-compatible API с собственным ключом/моделью/денежным бюджетом, без обязательного Codex CLI. Крестик завершает приложение; обновления вручную установщиком с сохранением данных. Windows 10 требует проверки на целевом ПК.

Установщика и API-режима пока нет. [Первый запуск](context/architecture/04-потоки/первый-запуск-десктопа.md) и [приёмка на другом ПК](context/architecture/06-решения/приёмка-десктопа.md) описывают целевой сценарий. Реализация — отдельное поручение, этапы 8D в [roadmap](context/architecture/08-дорожная-карта/roadmap.md). Последний ранее зафиксированный полный результат прототипа — 141 тест и production-build; в архитектурной сессии они повторно не запускались.

## Запуск существующего прототипа из исходников

Node.js 24+, установленный Google Chrome. После `npm install`:

```powershell
npm run build
npm start
```

Открыть http://127.0.0.1:8787/. Вход в Pinterest выполняется вручную в отдельном окне приложения. Профили, SQLite, изображения и промежуточные результаты хранятся в `.local/pma/`. Для проверки кода: `npm test`.

Существующее подключение сначала защитите локальным паролем: остановите старый сервис, выполните `npm run password`, выберите своё подключение и введите отдельный пароль PMA дважды (12–256 символов, ввод скрыт). Затем `npm start`. У нового подключения пароль задаётся в форме до открытия Chrome. Пароль Pinterest вводится только в Pinterest. Сессия PMA действует 30 минут; «Заблокировать PMA и закрыть Chrome» останавливает фоновые операции, сохраняет данные и отзывает коды Figma. Перезапуск начинается заблокированным. Пароль защищает доступ через приложение; прямой доступ к файлам той же Windows-учётной записи этой границей не закрыт.

Если подключение сохранено, но Chrome/Pinterest не открылся, используйте «Открыть Pinterest снова» в том же профиле. Повторно создавать подключение и задавать пароль не нужно. Для `ERR_NETWORK_ACCESS_DENIED` нужен запуск сервиса с разрешённым доступом к Pinterest; это не ошибка локального пароля.

До 100 AI-запусков в календарный месяц Europe/Moscow на экземпляр PMA, включая начатые ошибочные/отменённые вызовы; неизвестный вызов автоматически не повторяется. `PMA_AI_MONTHLY_CALLS` позволяет настроить другой положительный конечный предел. Это число inference, не размер квоты подписки. Режим OpenAI-compatible API со своим ключом согласован как будущее расширение и ещё не реализован.

Данные хранятся до явного удаления владельцем; автоматической очистки нет. Пользовательское локальное удаление ещё не реализовано. Локальное удаление и внешние пины/фреймы — разные действия. [Текущие доказательства и оставшиеся ручные шаги G2](context/architecture/06-решения/протокол-g2-2026-11-05.md).

## Подготовка запроса из замысла

В новом задании выберите «Опишу замысел», опишите желаемое пространство и нажмите «Подготовить поиск». Codex CLI предложит краткое понимание и конкретную формулировку; её можно исправить или выбрать альтернативу. Поиск запускается только отдельной кнопкой. При существенной неоднозначности возможен один вопрос; ответ создаёт новую версию с ещё одним явно указанным AI-вызовом.

«У меня готов запрос» идёт напрямую без AI-подготовки. Ссылка на Pinterest-пин распознаётся без inference. Чистый Lens использует фото напрямую; подготовка текста не выдаётся за анализ картинки. AI-отбор найденных изображений включается отдельно. «Сохранённые описания» позволяют вернуться к готовой или незавершённой подготовке своего проекта без скрытого повторного расхода. Интерпретация входит в общий месячный предел 100 вызовов, unknown автоматически не повторяется. [Доказательства и ограничения](context/architecture/06-решения/журнал-решений/2026-11-05-замысел-в-поисковый-запрос.md).

## Если Pinterest запросил проверку

Нажать «Открыть Pinterest», вручную пройти показанную проверку или вход, затем «Продолжить поиск». Повтор выполняется только по этому действию пользователя и в исходном аккаунте. Во время паузы сохраняются ссылки на найденные пины, загруженные изображения и выбор. Продолжение после перезапуска также доступно; автоматического перезапуска поиска нет.

Детектор различает видимую проверку и фоновые/скрытые CAPTCHA-элементы. При настоящей проверке поиск останавливается. Диагностика в `.local/pma/diagnostics/` содержит геометрию и URL без параметров; cookies, поля входа и ответы CAPTCHA не читаются. Старые остановки до исправления 3 ноября хранили только счётчик найденных пинов; утраченные тогда ссылки восстановить из счётчика нельзя, продолжение заново получает результаты по тому же заданию.

## Поиск по фото

При первом добавлении фото в новом задании автоматически выбирается Pinterest Lens, если пользователь ещё не выбрал режим явно. Перед запуском показывается исходное изображение. Текстовый режим передаёт в Pinterest только текст; при включённом AI приложенные фото используются на последующем этапе отбора. Режим и исходное фото видны и у готовой подборки.

Адаптер дожидается загрузки Pinterest, раскрывает свёрнутую строку поиска, открывает Lens, передаёт первое фото и подтверждает переход на визуальную выдачу. Подтверждение хранит стратегию и ID конкретного примера; без него image-задание не становится готовой подборкой. Текстовой подмены при ошибке нет. На пользовательском PNG проверены два успешных запуска по 25 изображений через `/lens-search/`.

Lens ищет по первому фото целиком. Если включить AI, приложение дополнит Lens кандидатами текстового поиска Pinterest и оценит общий пул по тексту, пояснению и всем примерам. Если дополнительная выдача пуста, это явно показано; результаты Lens сохраняются. Выбор области ещё не реализован.

## AI-отбор в обычном поиске

В новом задании включить «AI-отбор найденных изображений» и проверить условия перед запуском. Нужен установленный Codex CLI со штатным входом через ChatGPT на этом ПК. CLI здесь вызывает модель для оценки изображений; поиск и загрузку выполняет Playwright. Модель не управляет браузером и не сохраняет пины.

До 50 кандидатов, до трёх примеров, 24 МиБ изображений и один запуск модели до 180 секунд на задание. Рекомендуются до 25; недобор допускается. Вкладки «AI-отбор», «Все», «Выбранные» отделяют рекомендации от вашего решения. Карточки содержат пояснения, раздел «Источники и расход AI» — фактические usage, когда они доступны. Это расход квоты подписки, не безлимитный бесплатный API.

При ошибке, отмене или неизвестном результате модель автоматически не запускается повторно; найденные изображения доступны вручную. Повторный поиск — новое явное задание. Детали и доказательства — [ADR 0005](context/architecture/06-решения/журнал-решений/2026-11-03-ai-отбор-в-поиске.md).

## Точечные замены

Нажать «Заменить этот кадр» под одним или несколькими изображениями (до пяти), затем «Найти замены». Указать причину, проверить короткий текстовый запрос Pinterest и при желании включить AI. Создаётся отдельная версия; предыдущая сохраняется.

После поиска выбрать старое место и новый вариант, затем «Применить замены». Можно заменить часть отмеченных мест или «Оставить исходный набор». Остальные карточки, порядок и ручной выбор сохраняются. До решения по вариантам подготовка Figma этой версии недоступна. Для исходной истории — до трёх попыток, до 20 новых вариантов и один AI-вызов на попытку. Сбой модели оставляет пул для ручного просмотра; автоматического повторного расхода нет.

Доказательства, восстановление и ограничения — [ADR 0006](context/architecture/06-решения/журнал-решений/2026-11-05-точечные-замены.md).

## Экспорт выбранного набора

«Экспорт выбранного» фиксирует до 25 изображений вместе с порядком, исходными ссылками и SHA файлов. Последующее изменение выбора не меняет этот пакет. В окне отправки есть просмотр зафиксированного набора и отдельные статусы двух назначений.

Pinterest сохраняет существующие пины в одну секретную доску проекта исходного аккаунта. Имя автоматически укладывается в 50 символов. Проверяются владелец, секретность и фактические изображения на доске; исходный и сохранённый Pinterest ID могут различаться. Создание доски уже сохраняет первый пин. После неопределённого результата сначала выполняется чтение доски, повторная запись без сверки запрещена. Задержка выдачи допускает три чтения без повторного сохранения. Живая проверка подтвердила семь из семи выбранных изображений на новой секретной доске.

В Figma Desktop явно запустить «PMA — локальная проба импорта», вставить код из PMA и нажать «Загрузить и сверить подборку», затем «Создать или завершить фрейм». Код действует 15 минут и привязан к одной попытке; при истечении обновляется в том же окне PMA. Повтор сверяет фрейм, изображения и ссылки; частичная загрузка продолжается в прежних неизменённых объектах. Ручная правка, удаление или потеря меток останавливают восстановление. Отдельный новый фрейм создаётся только через соответствующий пункт PMA. Старые фреймы не перезаписываются. Живой native-импорт подтвердил семь изображений и семь ссылок в отдельном фрейме; повторная сверка вернула тот же фрейм без дубля. Всего 98 тестов проходят.

См. [ADR 0007](context/architecture/06-решения/журнал-решений/2026-11-05-независимые-экспорты.md).

## Проверка AI-отбора через Codex CLI

Для разработки сохранено отдельное сравнение «по фото» / «по фото и тексту» на уже сохранённых кандидатах. По выбору пользователя используется штатный вход Codex CLI через ChatGPT; отдельный API-ключ не нужен. У исходных подборок в веб-интерфейсе появляется «Открыть сравнение». Это отдельный эксперимент с двумя вызовами, обычный AI-поиск делает один.

Ручной запуск разработчиком:

```powershell
node scripts/evaluate-selection.mjs --source-run "ID_LENS" --text-run "ID_TEXT"
```

Нужны две готовые подборки одного проекта/владельца. Модель выбирается из реального каталога CLI, либо задаётся `--model`; перед запуском проверяется её наличие. Максимум два последовательных процесса по 180 секунд и 50 кандидатов. Результат хранится отдельно и не меняет выбор/экспорты. Токены учитываются по usage; точный процент квоты подписки не рассчитывается. Ограничения и первый результат — [ADR 0004](context/architecture/06-решения/журнал-решений/2026-11-03-ai-отбор-codex-cli.md).
