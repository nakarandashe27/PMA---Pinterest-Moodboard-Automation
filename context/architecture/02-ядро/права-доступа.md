# Права доступа

Статус: локальный пароль PMA и проверки HTTP/media/plugin реализованы, автоматическая часть проверена. Второй настоящий аккаунт ещё требует ручной проверки; G2 открыт. [ADR 0008](../06-решения/журнал-решений/2026-11-05-изоляция-и-пределы-g2.md), [матрица G2](../06-решения/протокол-g2-2026-11-05.md).

| Действие | Активный владелец | Технический оператор | AI |
|---|---|---|---|
| Подключить свой Pinterest | сам, ручная авторизация | сам для своего подключения | запретить |
| Читать/изменять свой проект и выбор | сам | только при явном доступе владельца | только предоставленные данные задачи |
| Подтвердить бриф и поиск | сам | сам в своей тестовой задаче | спросить |
| Интерпретировать, оценивать, группировать | сам запускает | сам запускает | сам внутри подтверждённого задания |
| Заменить выбранные карточки | сам | в своей задаче | спросить |
| Сохранить просмотренный выбранный набор | сам | в своей задаче | только детерминированный сервис после подтверждения |
| Импортировать в открытый Figma | сам запускает плагин | в своём файле/тесте | запретить самостоятельный запуск |
| Читать чужие проекты/секреты | запретить | нет неявного права | запретить |
| Удалять внешние доски или менять публичность | вне пилота | вне пилота | запретить |

«Спросить» означает предусмотренное действие пользователя в продукте, а не дополнительное подтверждение каждой внутренней операции.

Права проверяются по неизменному ID владельца задачи, проекта и назначения. Активный аккаунт в UI не является источником владельца фонового задания. Задача от A никогда не использует подключение B. Технический оператор не становится владельцем всех подключений.

До сохранения проверять выбранную версию, аккаунт и секретность доски. Ограничения API/Trial/Standard не обходятся общей авторизацией владельца приложения.

Имя подключения и `settings.activeConnectionId` не аутентифицируют. Данные и сохранённый профиль Chrome открываются отдельным паролем PMA этого подключения; пароль Pinterest вводится только в Pinterest. Один активный владелец, сессия 30 минут, новый процесс начинает заблокированным. Блокировка/смена/истечение отзывают доступ и pairing-коды, останавливают jobs; продолжение явное. Первичная защита старых подключений/сброс пароля — только доверенная локальная команда, без HTTP-сброса. Прямой доступ к файлам той же учётной записи ОС вне этой границы.
