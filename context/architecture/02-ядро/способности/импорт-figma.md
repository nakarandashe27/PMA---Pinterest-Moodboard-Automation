# Импорт в Figma Design

Статус: импорт снимков и восстановление реализованы. Живой native-импорт семи изображений/ссылок и повтор без дубля подтверждены; сбои и ручные конфликты проверены автоматически. Второй аккаунт/ПК остаются G2.

## Когда применять

Есть подтверждённый снимок выбора; архитектор открыл нужный файл Figma Design и явно запустил импорт в нашем плагине.

## Граница

Новый именованный фрейм на подборку/новый экспорт. Изображения и подписи/URL — отдельные редактируемые объекты. Старые ручные фреймы не изменяются.

## Примеры

Корректно: получить пакет конкретного аккаунта/снимка, создать объекты, записать node ID и фактические ошибки.
Некорректно: вставить один растр всей доски или по таймауту создать второй такой же фрейм.

## Сбои

Проверить изображения, размеры, доступные шрифты и связь плагина с сервисом. При повторе той же попытки найти её созданные объекты по квитанции/меткам в текущем документе и восстановить недостающее. Применимость конкретного механизма меток и идентификации файла — часть теста, а не готовая гарантия.

Источник: [Images](https://developers.figma.com/docs/plugins/working-with-images/), [Text](https://developers.figma.com/docs/plugins/working-with-text/), [Network](https://developers.figma.com/docs/plugins/making-network-requests/) (проверено 2026-11-02).

См. [проверки](../../06-решения/проверка-интеграций.md), [состояния](../../04-потоки/сценарий-и-состояния.md).

## Конфликт с ручной работой

Реализация 2026-11-05: пакет v2 привязан к snapshot/attempt, содержит SHA каждого файла; код подключения действует 15 минут. Сервис выдаёт эксклюзивную аренду на 120 секунд, плагин фиксирует ID фрейма до наполнения и хранит структуру/исходные ссылки/хеши image fills. Перед повтором сравнивает геометрию, текст, порядок и состав узлов. Завершённый импорт повторно проверяется без создания дубля. Полная квитанция должна совпасть с упорядоченным снимком. Поздняя квитанция относится только к своей попытке.

Локальный маркер документа не является глобально достоверным fileKey и может копироваться вместе с документом. Приватный Plugin API не включён. Изоляция на другом ПК/аккаунте и жизненный цикл доступа остаются частью G2. Семь тестов native-совместимого ядра дополняют живой native-запуск: фрейм 30:2, семь image fills и семь исходных URL, повтор без второго фрейма. Исправлены отсутствие Web Crypto в UI sandbox и обработка пересланных ответов Figma. См. [ADR 0007](../../06-решения/журнал-решений/2026-11-05-независимые-экспорты.md).

Если во время восстановления обнаружены ручные изменения, потеря меток или неоднозначная связь attempt→фрейм, остановить восстановление с конфликтом. Не перезаписывать и не воссоздавать вручную удалённые/изменённые объекты молча. Новый полный импорт возможен только как явно выбранная пользователем новая попытка. Проверить этот сценарий отдельно.
