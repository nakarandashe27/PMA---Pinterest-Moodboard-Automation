# Подключения и аккаунты

Статус: локальный DOM-adapter с отдельными Chrome-профилями реализован; пароль PMA защищает открытие профиля/данных. Проверка второго настоящего аккаунта ещё не проведена. [G2](../../06-решения/протокол-g2-2026-11-05.md).

## Когда применять

Ручное подключение владельцем своего Pinterest; переход между подключёнными аккаунтами. Сначала аккаунт инициатора, затем архитектора.

## Граница

Один активный пользователь локального экземпляра. Переключатель Pinterest не является полноценной серверной системой аутентификации сотрудников.

## Примеры

Корректно: после подключения показать проверенные ID/username, открыть только проекты этого владельца.
Некорректно: получить имя из произвольного поля и продолжить старое задание новым токеном.

## Сбои

Отозванный доступ требует повторного подключения того же владельца. Задачи сохраняют владельца и не передаются другому аккаунту. Новые внешние записи при несовпадении аккаунта блокируются.

Официальный Authorization Code предусмотрен для независимых конечных пользователей; Client Credentials действует от владельца приложения. Доступ Trial/Standard и secret scopes проверяются отдельно. Источник: [OAuth](https://developers.pinterest.com/docs/getting-started/set-up-authentication-and-authorization/) (проверено 2026-11-02).
