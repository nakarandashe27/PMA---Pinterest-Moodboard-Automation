# Получение кандидатов Pinterest

Статус: согласованная функция; локальный DOM-адаптер реализует текстовый поиск и внешний Lens. На 2026-11-03 пользовательский PNG дважды дал по 25 изображений через `/lens-search/`. Переносимость и условия постоянного использования остаются открытыми.

Lens дожидается готовности интерфейса и при необходимости раскрывает `Search icon`, затем вызывает именно загрузку изображения Lens. После передачи файла подтверждается визуальный URL; в задании сохраняются стратегия и ID seed-загрузки. Без подтверждения соответствующего seed результат не выдаётся за image-search. Режим, фото и предупреждение о неиспользовании фото в текстовом режиме видны пользователю. Текстовые пожелания не применяются к Lens автоматически; выбранное фото используется целиком. См. [ADR 0003](../../06-решения/журнал-решений/2026-11-03-локальный-прототип.md).

## Когда применять

После подтверждения интерпретации искать по тексту, внешнему примеру через Lens, существующему пину/crop или related. Нативные механизмы Pinterest — приоритет исследования.

## Граница

Все найденные источники — Pinterest. Загруженный пример не разрешает поиск на других платформах. AI не заменяет непроверенный Lens автоматически текстовым поиском.

## Примеры

Корректно: записать pin ID, каноническую ссылку, изображение, использованную стратегию и seed.
Некорректно: вернуть только JPEG без ссылки или назвать найденным пином выдуманный ID.

## Сбои

Сохранять полученное по этапам; ограничивать число итераций и стоимость. Авторизация, CAPTCHA, запрет доступа и ограничения платформы — состояния для остановки/участия пользователя, без циклов обхода. Неполную выдачу показывать с причиной.
