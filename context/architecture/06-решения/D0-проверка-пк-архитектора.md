# Проверка компьютера перед установкой PMA

Это займёт 2 минуты. Команда ничего не устанавливает и не меняет, а только показывает сведения о компьютере.

## Что сделать

1. Нажмите **Пуск**, введите `PowerShell` и откройте **Windows PowerShell** (обычный запуск, не от имени администратора).
2. Скопируйте весь блок ниже, вставьте в окно (правой кнопкой мыши) и нажмите **Enter**.
3. Через 10–20 секунд появятся 7 строк. Выделите их, скопируйте и пришлите в ответ. Можно прислать скриншот.

```powershell
$os = Get-CimInstance Win32_OperatingSystem
$chrome = @("$env:ProgramFiles\Google\Chrome\Application\chrome.exe","${env:ProgramFiles(x86)}\Google\Chrome\Application\chrome.exe","$env:LOCALAPPDATA\Google\Chrome\Application\chrome.exe") | Where-Object { Test-Path $_ } | Select-Object -First 1
$admin = ([Security.Principal.WindowsPrincipal][Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator) -or ((whoami /groups) -match 'S-1-5-32-544')
"Windows: $($os.Caption) $($os.Version) (сборка $($os.BuildNumber))"
"Разрядность: $($os.OSArchitecture)"
"Chrome: $(if ($chrome) { (Get-Item $chrome).VersionInfo.ProductVersion } else { 'не найден' })"
"Figma Desktop: $(if (Test-Path "$env:LOCALAPPDATA\Figma\Figma.exe") { 'установлена' } else { 'не найдена' })"
"Права администратора у учётной записи: $(if ($admin) { 'есть' } else { 'нет' })"
"Pinterest доступен: $((Test-NetConnection www.pinterest.com -Port 443 -WarningAction SilentlyContinue).TcpTestSucceeded)"
"Свободно на диске C: $([math]::Round((Get-PSDrive C).Free/1GB)) ГБ"
```

## И ответьте на три вопроса

1. Работаете в Figma в **приложении** или **в браузере**?
2. Компьютер рабочий (есть системный администратор или ограничения на установку программ) или личный?
3. Pinterest-аккаунт для работы у вас **свой**, или нужно завести отдельный?

---

*Для команды PMA:* ответы заполняют строку D0 в [приёмке десктопа](приёмка-десктопа.md). Проверка 2026-11-09 на ПК разработчика: команда работает на Windows 10 Pro 19045 x64.
