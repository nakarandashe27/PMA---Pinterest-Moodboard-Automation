# Приёмка десктопного PMA на другом ПК

Дата плана: 2026-11-06. **Все desktop-gates ниже открыты; это критерии, не протокол выполненных тестов.** Архитектура согласована в [ADR 0011](журнал-решений/2026-11-06-десктопное-приложение.md). Последние 141 тест/build относятся к прежнему локальному прототипу и здесь не запускались повторно.

## Порядок и доказательства

Проверки планируются после отдельного поручения на реализацию. Сначала искусственные данные и заглушки внешних мутаций, затем настоящий установленный пакет/чистое окружение, затем необходимые разрешённые живые действия владельца. Старые успешные экспорты не повторять для получения desktop-галочки.

Для каждой строки сохранить: версию/хеш сборки и плагина, OS/build/arch, сценарий и исходные условия, ожидаемое/фактическое, обезличенное свидетельство и ограничения. Секреты, пользовательские изображения и приватные URL не включать в context; приватные доказательства хранить отдельно. Закрывать строку только по соответствующему результату, не по наличию кода.

## Допуск к передаче

Установщик считается технически пригодным только после применимых D0–D24 с явными результатами/пределами. Если проверка невозможна или провалена, фиксируется причина и решение; пустая строка не превращается в «не применимо» ради выпуска. Неразличимость точной копии Figma без fileKey — известное ограничение, а не тест, который можно объявить успешно устранённым.

Самостоятельный пилот дополнительно требует открытых живых сценариев G2 и реального G3. Сборка документации, зелёный prototype test suite и наличие Electron не закрывают эти gates.
