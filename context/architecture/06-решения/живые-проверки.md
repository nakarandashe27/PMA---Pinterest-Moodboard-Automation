# Живые проверки перед пилотом

Подготовлено 2026-11-10. Это сценарий для людей: пароли PMA, вход в Pinterest, Figma и API-ключ вводят только владелец или архитектор. Автоматические проверки уже пройдены (173 теста, 23 проверки установленной программы); здесь только то, что нельзя доказать на заглушках. Результат каждой строки записывайте в бланк в конце; после заполнения gates в [приёмке](приёмка-десктопа.md) и [G2](протокол-g2-2026-11-05.md) обновляются по фактам.

Правила:
- Используется установщик `release/PMA-Setup-0.1.0-x64.exe`; перед установкой сверить SHA-256 из `.sha256` (`certutil -hashfile <файл> SHA256`).
- Внешние записи (пины, доски, фреймы) делаются только в тестовых проектах и секретных досках; ничего внешнего не удалять.
- Если шаг даёт неожиданный результат — остановиться, сделать снимок экрана, нажать «Состояние PMA → Создать отчёт для помощи» и не повторять платные или записывающие действия.
- Установленная PMA хранит данные в `%LOCALAPPDATA%\PMA`. На ПК владельца там уже есть данные от 9 ноября: первый запуск сам сделает backup и обновит схему.

## Сеанс 1 — ПК владельца (≈1 час)

Подготовка: закрыть прототип на 8787 (иначе мост Figma в desktop будет «недоступен», это проверка L5, но не помеха остальному) или наоборот оставить его — тогда сначала проверить L5.

| ID | Что делать | Ожидаемый наблюдаемый результат | Закрывает |
|---|---|---|---|
| L1 | Установить PMA, открыть с ярлыка. Открыть своё подключение паролем PMA | Окно PMA, проекты владельца. «Состояние PMA»: версия 0.1.0, мост Figma работает | D1 (на этом ПК), D2 |
| L2 | «Настройки AI»: заполнить профиль по документации своего провайдера (адрес, формат, модель, изображения и их предел токенов, предел вывода, тариф, «рассуждения входят в предел вывода», денежный предел). Сохранить ключ. Нажать «Платная проверка» | «Профиль проверен (текст и изображения)»; расход за месяц > 0 и ≤ верхней оценки; в кабинете провайдера ровно один запрос. Записать токены и сумму из PMA и из кабинета | D12 |
| L3 | Новое задание «Опишу замысел» → «Подготовить поиск» → поправить формулировку → запустить поиск с AI-отбором | Формулировка готова за один вызов; поиск находит изображения; AI-отбор даёт рекомендации; в «Настройках AI» +2 вызова, сумма совпадает с кабинетом провайдера в пределах округления | D12 |
| L4 | Повторить L2 со вторым endpoint или вторым форматом (Responses ↔ Chat Completions), если провайдер его поддерживает | Проверка пройдена или понятный отказ до вызова (например, нет изображений). Записать, какой формат/провайдер | D13 |
| L5 | Если прототип на 8787 работает: открыть экспорт в desktop | В экспорте нет кода Figma, сообщение «порт занят»; прототип продолжает работать. Затем закрыть прототип и перезапустить PMA — мост работает | D8 (живой) |
| L6 | «Состояние PMA → Открыть папку плагина». В Figma Desktop: Plugins → Development → Import plugin from manifest → `manifest.json` из этой папки. Экспортировать тестовую подборку в новый фрейм; затем повторить загрузку тем же кодом | Фрейм с отдельными изображениями и ссылками; статус «Изображения и ссылки сверены»; повтор не создаёт второй фрейм | D20 (на этом ПК), D9 |
| L7 | Закрыть PMA и окно плагина, переустановить тот же установщик поверх, открыть PMA, запустить плагин заново | Данные на месте, путь плагина тот же, импорт работает без повторного Import | D21 |
| L8 | Запустить поиск под A; во время поиска заблокировать PMA и открыть B; затем снова открыть A | B не видит проект A; поиск A в статусе «можно продолжить»; «Продолжить поиск» завершает его без дублей | G2 «переключение во время задания» |
| L9 | В окне Chrome PMA выйти из Pinterest A; запустить поиск; затем войти обратно в A и нажать «Продолжить поиск» | Поиск встаёт на паузу «нужен вход», после входа продолжается тем же заданием | G2 «восстановление после входа A» |
| L10 | Во время поиска закрыть PMA крестиком; открыть снова | PMA закрылась быстро; своих окон Chrome не осталось (ваш обычный Chrome не закрыт); поиск можно продолжить | D10 (живой) |
| L11 | Отправить установщик и `.sha256` архитектору выбранным каналом | Канал и способ сверки записаны | D24 |
