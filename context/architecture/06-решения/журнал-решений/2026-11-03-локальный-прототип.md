# ADR 0003: локальный прототип и остановка при проверке Pinterest

Дата: 2026-11-03. Статус: реализовано для технической проверки на ПК инициатора; готовность самостоятельного пилота не подтверждена.

## Основание

После G1 пользователь поручил углублённое исследование OSS, затем создание веб-интерфейса. [Исследование 19 репозиториев с разбором 10 реализаций](../../../../research/2026-11-03-pinterest-oss/README.md) не подтвердило готовую библиотеку для всей цепочки. Для ближайшей проверки выбран небольшой собственный адаптер; это не утверждение его превосходства или разрешения Pinterest на постоянное применение.

## Решение

React/TypeScript/Vite, один локальный Node.js 24+ процесс, встроенный SQLite, каталог управляемых файлов. Playwright открывает отдельный постоянный Chrome-профиль на подключение. Сбор ограничен временем, прокрутками и количеством; изображения берутся из DOM-карточек с исходными pin ID/URL. Загруженные файлы проверяются по сигнатуре, ограничиваются размером и удаляются из набора при точном совпадении SHA-256. Это ещё не CV-оценка соответствия и визуального разнообразия.

На каждом шаге сбора найденные ссылки сохраняются в задании. Видимая проверка/вход переводит задание в `blocked`; скачивание после обнаружения проверки не запускается. Фоновый invisible-reCAPTCHA badge, прозрачный, скрытый или обрезанный iframe сами по себе не являются подтверждением проверки. Это различие согласуется с [документацией invisible reCAPTCHA](https://developers.google.com/recaptcha/docs/invisible); содержимое challenge и его ответы не читаются.

«Открыть Pinterest» показывает существующую страницу профиля. «Продолжить поиск» — отдельное действие пользователя с проверкой исходного владельца. Сохранённые ссылки повторно нормализуются; загруженные изображения и выбор сохраняются. Возобновление после перезапуска явное, без фонового retry. Старые ошибки доступа становятся доступными для продолжения, но потерянные прежней версией ссылки не выдумываются из счётчика.

Веб-интерфейс готовит неизменный снимок выбора и отдельный пакет Figma, доступный плагину по временному коду. Технический импорт G1 на 25 изображений проверен ранее; новый путь произвольного выбранного набора требует отдельной живой проверки в Figma.

## Проверка и ограничения

На запросе пользователя «Частные сады» после исправления получены 25 локальных изображений со ссылками, показаны в веб-интерфейсе. Старые журналы не содержат DOM-доказательства причины прежнего сообщения; нельзя утверждать, что тогда точно была либо отсутствовала настоящая CAPTCHA. Проверены 29 тестов, включая rendered DOM Chrome для скрытых/видимых challenge и сохранение 29 найденных ссылок через паузу, перезапуск и продолжение. Сборка проходит. Проверены кнопки паузы на ширине 390 px и результат на 1280 px.

### Исправление Lens в тот же день

По истории пользователя подтверждён реальный сбой `Не удалось найти Pinterest Lens`; последующие задания с тем же фото имели `mode=text`. Диагностика показала сначала ещё пустой DOM после навигации, затем свёрнутый поиск с кнопкой `Search icon`, без доступной кнопки Lens. Адаптер теперь ожидает отрисовку и раскрывает строку поиска перед Lens. Выбор файла относится к Lens, а не к произвольному file input; результат подтверждается переходом на визуальную выдачу и связывается с ID исходного примера.

На том же PNG два запуска дали по 25 изображений, оба с подтверждением `/lens-search/`; второй запущен из веб-формы. В первом наборе нет совпадений pin ID с предыдущим текстовым набором пользователя; это частное сравнение, не benchmark качества. Форма выбирает Lens при первой загрузке фото, если режим ещё не выбран явно, показывает seed на подтверждении и предупреждает о текстовом режиме. У результата видны основа поиска и исходное фото. Текст/пояснения поверх Lens, crop и CV-отбор ещё не реализованы. Регрессионные тесты проверяют задержку отрисовки, свёрнутый поиск, два потока загрузки, отсутствие перехода на Lens, неверный seed и отмену до передачи файла.

AI-интерпретация/ранжирование, похожие визуальные дубли, точечные замены, группировка, автоматический SECRET-save, два независимых подтверждённых экспорта, второй реальный аккаунт и ПК архитектора остаются незавершёнными. Условия постоянного использования Pinterest не закрыты. См. [дорожную карту](../../08-дорожная-карта/roadmap.md) и [исходную рамку](2026-11-02-основа.md).
