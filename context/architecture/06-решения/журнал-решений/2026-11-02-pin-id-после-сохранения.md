# ADR 0002: исходный и сохранённый pin ID

Дата: 2026-11-02. Статус: принятое инженерное уточнение по фактическому UI-тесту; продуктовый замысел не меняется.

## Наблюдение

При сохранении выбранного существующего публичного пина в новую private board Pinterest показал на доске пользовательский сохранённый экземпляр с другим ID. Источник, сохранённая картинка и ожидаемая доска подтверждены наблюдениями. Это не загрузка скачанной копии как нового контента.

## Решение

Разделить `sourcePinId/sourcePinUrl` и `savedPinId/savedPinUrl` в ExportReceipt, сохранять board ID и владельца. PinReference и ссылки Figma продолжают указывать на исходный источник. Новая связь saved ID не заменяет его.

Readback не требует равенства IDs. Нужны подтверждённое назначение, происхождение сохранения и ожидаемое изображение. Один и тот же image URL/hash сам по себе не является универсальным доказательством авторства или любой сложной lineage.

## Последствия

Повторы и дедупликация используют квитанции и отображение source→saved; нельзя повторять save только потому, что исходный ID не найден среди новых ID доски. Изменение записано до реализации основной БД.
