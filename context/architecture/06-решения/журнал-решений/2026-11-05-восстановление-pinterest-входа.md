# ADR 0010: пауза при утрате Pinterest-личности

Дата: 2026-11-05. Статус: исправлено и автоматически проверено; live-остановка подтверждена, live-продолжение после повторного входа ещё ожидается.

## Наблюдение

После ручного выхода пользователя из Pinterest A новый тестовый поиск без AI остановился до получения карточек: 0 изображений, неизменный owner A. Однако helper проверки личности выбросил обычный AppError; worker записал `error`, а не `blocked`, поэтому UI не предложил явное продолжение. Уже существовавшая подборка из 25 изображений была получена раньше и не служит доказательством состояния после выхода.

## Решение

Отсутствующий username и несовпадение с сохранённым аккаунтом — PinterestAccessError с причиной login. Это не разрешение менять connectionId задачи или использовать B. Worker сохраняет checkpoints, файлы, выбор и владельца; после ручного входа в исходный аккаунт возможен только явный resume.

Во время DOM-сбора ожидаемая личность проверяется перед и после чтения каждой порции карточек. Если она сменилась, порция другого владельца не передаётся в checkpoint. Флаг занятости браузера освобождается и при остановке. При перезапуске только известные старые login-сообщения переводятся из error в blocked без повторения поиска; другие ошибки не переклассифицируются.

## Проверка

Пять новых тестов: отсутствие/несовпадение личности с сохранением owner/выбора и явным продолжением; смена между порциями и во время чтения; точечное восстановление старых сообщений без удаления данных. Полный `npm test`: 122 passed, синтаксис изменённых модулей проверен. [Тесты](../../../../server/test/pinterest-identity.test.mjs).

После штатного перезапуска новый реальный test-run находится в blocked/login, AI выключен, 0 кандидатов, owner A. Предыдущий готовый run с 25 изображениями сохранён, экспортные записи до/после имеют ту же контрольную сумму. Для завершения живого испытания владелец должен вновь открыть A локальным паролем, войти в Pinterest A и явно продолжить этот же run. Ни inference, ни повторных Pinterest/Figma-экспортов в этой проверке не было.
