# Архитектура PINTEREST MOODBOARD AUTO

Контракт между будущим разработчиком и AI о целевой системе. Исходная дата: 2026-11-02; desktop-решение согласовано 2026-11-06.

## Текущий план разработки

[08-дорожная-карта/roadmap.md](08-дорожная-карта/roadmap.md) — этапы и критерии готовности. Для отдельного поручения на desktop-реализацию начинать с 8D.1; открытые G1/G2/G3 остаются самостоятельными gates.

[ADR 0011](06-решения/журнал-решений/2026-11-06-десктопное-приложение.md) и [desktop-контракт](05-стек/десктопное-приложение.md) — согласованная целевая поставка: Electron/utilityProcess, ограниченный UI IPC, API первого релиза, отдельный Figma bridge. Установщик, desktop и API-режим ещё не реализованы. [Первый запуск](04-потоки/первый-запуск-десктопа.md), [приёмка](06-решения/приёмка-десктопа.md), [изолированный premortem](07-нефункциональные/риски-десктопа.md).

## Статусы

**Реализовано** — код и доказательства. **Согласовано / запланировано** — принятое поведение, реализация может отсутствовать. **Предложено / гипотеза** — уточнение механизма. **Требует проверки** — испытание не выполнено. После [проб G1](06-решения/протокол-g1-2026-11-02.md) создан [локальный прототип](06-решения/журнал-решений/2026-11-03-локальный-прототип.md), затем интерпретация, AI-отбор, замены, независимые экспорты и автоматическая часть изоляции. Последний результат — 141 тест/build; перенос и самостоятельный пилот ещё не выполнены.

Подтверждённые требования — [реестр решений](../idea/04-mvp/decisions.md). Технические модели ниже — целевой чертёж; реализованный стек/DOM-адаптер описан в ADR 0003. AI-провайдер и постоянные условия доступа Pinterest не выбраны/не закрыты.
