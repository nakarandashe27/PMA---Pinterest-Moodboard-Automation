# Сущности

Статус: предложенная логическая модель. Поля перечислены ради ответственности, а не как готовые миграции.

| Сущность | Назначение и основные поля | Связи |
|---|---|---|
| AccountConnection | Локальный id, подтверждённый Pinterest user ID при доступности, username, состояние, ссылка на секрет, тип подключения | Владелец проектов/задач; секрет отдельно от обычных данных |
| Project | id, account_id, название, optional board_id, подтверждённая privacy | Один владелец; одна secret board после первого сохранения |
| BriefVersion | id, project_id, исходный запрос, интерпретация, критерии, подтверждение | Версии задания проекта |
| InputReference | id, brief_version_id, управляемый путь файла, checksum, пояснение, нужная область | Пример для поиска, не найденный пин |
| SearchRun | id, account_id, project_id, brief_version_id, стратегия, состояние, время, лимиты | Устойчивый запуск, сохраняет владельца при переключении |
| PinReference | id, account_id, pin_id, canonical_url, media metadata, проверенный asset | Исходный Pinterest-пин; уникальность account_id+pin_id |
| RunCandidate | id, run_id, reference_id, provenance/seed, оценка/причина, группа, состояние | Один источник в контексте конкретного запуска |
| SelectionSnapshot | id, account_id, run_id, revision, подтверждение | Неизменный выбранный набор |
| SelectionItem | snapshot_id, candidate_id, закреплённая версия asset/checksum, порядок | Членство и порядок снимка |
| ExportAttempt | id, snapshot_id, target, destination_ref, статус, локальный ключ повтора | Два независимых назначения |
| ExportReceipt | attempt_id, reference_id, sourcePinId/URL, savedPinId/URL для Pinterest, ожидаемая версия asset, board ID либо Figma node ID, результат, ошибка | Фактический результат каждого элемента |
| JobEvent | run/attempt_id, время, этап, краткая причина | Восстановление и диагностика без секретов |

Связи выполняются по ID, не username, имени проекта или пути из пользовательского ввода. Предметные и приватные метаданные из одного аккаунта не объединяются в общий доступный каталог. Точная модель назначения Figma зависит от проверенных возможностей плагина.

См. [абстракцию](главный-кирпич.md), [ER](схема-связей.md), [инварианты](правила-нерушимые.md), [состояние](../02-ядро/память-и-состояние.md).

Сохранённый Pinterest ID не заменяет исходный. Причина и фактическое наблюдение: [ADR 0002](../06-решения/журнал-решений/2026-11-02-pin-id-после-сохранения.md).
