# Что не выбрано и почему

- **Конкретная Pinterest-библиотека:** чтение кода не заменяет проверку доступа и результата.
- **Собственный глобальный поиск/обучение visual model:** пользователь хочет использовать механизмы Pinterest; источник только Pinterest.
- **Неограниченный browser-agent loop:** поиск должен быть конечным, воспроизводимым и ограниченным по стоимости.
- **Микросервисы, Kubernetes, отдельный брокер:** нагрузка пилота не обосновывает эксплуатационную сложность.
- **Векторная БД и глобальная память:** сквозной поиск всего архива не согласован; локальное состояние достаточно.
- **PostgreSQL/серверная многопользовательская авторизация прямо сейчас:** это следующий этап, а не обязательная зависимость первого локального доказательства.
- **Telegram, Miro, FigJam и другие источники:** расходятся с подтверждённой областью.
- **Обязательный Docker:** наличие CLI не подтверждает engine или удобство интерактивной авторизации.
- **Конкретная платная модель:** качество, доступность и стоимость ещё не измерены.
- **Автоматическая синхронизация ручных правок:** новый фрейм на подборку сохраняет авторскую работу без сложного двустороннего механизма.

Это ограничения текущего плана, а не вечный запрет. Значимое изменение отражать в [журнале решений](../06-решения/журнал-решений/2026-11-02-основа.md).

## Десктопные альтернативы — решение 2026-11-06

- **Tauri + Node-sidecar:** допустимая альтернатива, но добавляет Rust/WebView2 и отдельную поставку Node к уже работающему Node/Playwright backend. Размер оболочки не перевешивает дополнительные связующие части пилота.
- **Electron + отдельный Node-runtime:** резервная гипотеза при провале utilityProcess, а не второй обязательный runtime заранее.
- **UI на loopback с автоматически добавляемым instance-secret:** исключён после изолированного premortem. Тот же origin после аварии может обслужить другой процесс. Выбраны упакованный app://pma UI и ограниченный IPC; loopback только Figma.
- **Обязательные Codex CLI/ChatGPT-подписка для архитектора:** не выбраны для первого релиза. Рабочий legacy-код сохраняется, минимум пилота — собственный API-профиль и бюджет.
- **Безусловная совместимость любого API по одному ключу:** не обещана. Разрешены настраиваемые endpoint/model; реальные text/image/schema/usage/billing capabilities проверяются.
- **Трей, фоновые auto-update и автоматический перенос .local/pma:** не входят в согласованную поставку. Крестик завершает PMA, обновления вручную, перенос данных отдельно.
