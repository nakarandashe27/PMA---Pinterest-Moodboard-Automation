# Технологии

Обновлено: 2026-11-06. **Реализован локальный прототип:** React 19/TypeScript/Vite, Node.js 24+ ESM, встроенный SQLite, локальные файлы и DOM-адаптер Playwright в отдельном persistent Chrome-профиле. Точные версии — в package.json/package-lock.json. Состояние задания, найденные ссылки и ручной выбор сохраняются; продолжение явное. Два настоящих аккаунта проверены, G2 остаётся открыт по живому восстановлению и активному переключению; перенос ещё не выполнен.

**Согласована, не реализована desktop-цель:** [ADR 0011](../06-решения/журнал-решений/2026-11-06-десктопное-приложение.md), [детальный контракт](десктопное-приложение.md). Таблица различает сегодняшний код и выбранное направление. История локального стека — [ADR 0003](../06-решения/журнал-решений/2026-11-03-локальный-прототип.md).

## Локальная проверка 2026-11-02

Проверка источников 2026-11-06: [Electron 45](https://www.electronjs.org/blog/electron-45-0) включает Node 24.22, но это не доказательство runtime PMA; [Playwright](https://playwright.dev/docs/intro#system-requirements) указывает Windows11+. На текущем ПК .NET показал Windows10.0.19045/X64, ОС архитектора ещё уточняется. Windows10 — отдельная проверяемая конфигурация. [Матрица runtime и первичные источники](десктопное-приложение.md#runtime-и-ос), [приёмка](../06-решения/приёмка-десктопа.md). Точные версии выбираются при реализации из поддерживаемых stable, не по размеру оболочки или preview-документации.

Ниже сохранены результаты прежних проверок и происхождение решений; desktop/API-реализация ими не подтверждается.

2026-11-05: добавлены локальный пароль PMA, отдельная тестируемая фабрика HTTP и атомарный месячный резерв AI. Пользователь подтвердил будущую альтернативу `openai-compatible` для людей без подписки ChatGPT Plus: endpoint/model и ключ владельца, явный выбор без автоматического fallback, мультимодальный структурированный ответ, отдельный бюджет. Исполнитель `invoke` отделён от prompt/schema/детерминированной проверки; API-adapter пока не написан. [ADR 0008](../06-решения/журнал-решений/2026-11-05-изоляция-и-пределы-g2.md).

Дополнение 2026-11-03: по выбору пользователя визуальный отбор работает через установленный Codex CLI и штатный ChatGPT-вход. Использован GPT-5.6-Sol из реального каталога CLI после отказа модели GPT-6.1-Sol. Отдельный API-ключ не создавался. После [сравнительной пробы](../06-решения/журнал-решений/2026-11-03-ai-отбор-codex-cli.md) включён [необязательный шаг обычного поиска](../06-решения/журнал-решений/2026-11-03-ai-отбор-в-поиске.md) с одним inference и отключёнными инструментами. Это локальное решение, не схема доступа общего сервера.

Дополнение 2026-11-05: [интерпретация свободного замысла](../06-решения/журнал-решений/2026-11-05-замысел-в-поисковый-запрос.md) также использует существующий Codex CLI/ChatGPT-вход: текстовый prompt, строгая JSON-схема, отключённые инструменты, до 90 секунд, общий месячный резерв. Полученный запрос подтверждает человек перед отдельным запуском Pinterest. Готовые запросы и чистый Lens пропускают AI-подготовку. OpenAI-compatible adapter остаётся будущим отдельным режимом; ключи для этой функции не создавались.

На исходной проверке окружения обнаружены Node 24.16.0, npm 11.9.0 и Git 2.54.0.windows.1. Chrome, Edge и Figma Desktop установлены. Python/py найдены как WindowsApps aliases, рабочий интерпретатор не подтверждён. Docker CLI 29.7.2 есть, доступность engine не подтверждена; из этого нельзя заключить, что достаточно только включить Docker Desktop. На момент этой проверки браузеры и контейнеры не запускались; последующие браузерные испытания описаны в ADR.

Перед выбором версий проверить официальную документацию совместимости и фактическое окружение ПК архитектора. Не требовать Python/Docker только из-за первоначального предположения.

Юрисдикция данных, корпоративная политика и доступность AI-провайдера **[заполнить позже]** перед серверным этапом/выбором провайдера. Локальный пилот не задаёт автоматически правовой режим публичного сервиса. Платежи, почта, биллинг и коммерческий хостинг в пилоте не нужны.
