# Замысел проекта

Рабочее название: **PINTEREST MOODBOARD AUTO**. Контекст согласован с пользователем 2026-11-02 после интервью Q1–Q29. Это описание будущего инструмента; работающая интеграция ещё не создана.

Внутренний веб-инструмент ландшафтного бюро превращает короткое задание и необязательные визуальные примеры в компактный черновик референсов из Pinterest. Архитектор выбирает изображения до отправки в Figma Design и секретную проектную доску Pinterest.

## Навигация

- [Идея](01-idea/README.md): проблема, мотивация и источники вдохновения.
- [Видение](02-vision/README.md): пользовательский сценарий и результат.
- [Аудитория](03-audience/README.md): первый пользователь и задачи.
- [Первая версия](04-mvp/README.md): состав и границы пилота.
- [Реестр решений](04-mvp/decisions.md): согласованные ответы интервью.
- [Исследование](05-research/README.md): первичные источники, аналоги и OSS.
- [Принципы](06-principles/README.md): правила будущей системы.
- [Риски](07-risks/README.md): независимый разбор сценария неудачи.

При работе читайте нужный раздел, не загружайте весь контекст сразу.
