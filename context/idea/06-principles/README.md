# Принципы проекта

Выведены из [задач архитектора](../03-audience/jobs-to-be-done.md), [исследования](../05-research/README.md) и [подтверждённых решений](../04-mvp/decisions.md).

1. Конечная полезная подборка важнее длительности просмотра и числа картинок.
2. Pinterest — единственный источник найденных референсов; его нативные поисковые механизмы исследуются первыми.
3. Архитектор видит интерпретацию и контролирует выбор перед экспортом.
4. Визуальный пример содержит конкретные признаки; весь кадр не обязан совпадать.
5. Источник, наблюдение и предположение различаются.
6. Данные и права привязаны к аккаунту, а не к текущему переключателю интерфейса.
7. Каждый этап сохраняет результат; повтор сбоя не создаёт дубли.
8. Последовательность доказательств: описание функции → наличие кода → проверка на аккаунте → сквозной пилот. Проверенная цепочка предшествует расширению функций.
9. AI используется для задач, где полезно понимание смысла: свободное описание → поисковая формулировка, необязательная оценка соответствия изображений. Авторизация, owner, загрузка, точные дубли, выбор, лимиты и экспорт выполняются детерминированно. Готовый запрос может обходить AI; отдельный inference ради решения «нужен ли AI» не требуется. Принцип прямо сформулирован пользователем 2026-11-05; [ADR 0009](../../architecture/06-решения/журнал-решений/2026-11-05-замысел-в-поисковый-запрос.md).
