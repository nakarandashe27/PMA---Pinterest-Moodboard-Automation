# Действия и подтверждения

| Действие | Условие |
|---|---|
| Интерпретировать введённое и предложить понимание примера | Пользователь передал задание/пример |
| Искать, анализировать и группировать | Пользователь подтвердил интерпретацию и запуск |
| Заменить кандидатов | Пользователь отметил карточки и причину |
| Сохранить пины в секретную доску | Явно выбран просмотренный набор, проект и аккаунт; есть действие сохранения |
| Создать фрейм Figma | Пользователь открыл файл и запустил плагин/импорт |
| Использовать платный анализ | Настроены разрешённый провайдер и лимит расходов; цена измеряется |
| Удалить чужую доску, публиковать новые пины, менять ручные правки Figma | Не входит в подтверждённый пилот |

Логин сам по себе не разрешает последующее сохранение любого найденного материала. Смена активного аккаунта не является разрешением выполнить старую задачу от нового пользователя.
