# Видение

Архитектор тратит время на проектное решение и окончательный выбор, а система выполняет ограниченный поиск и предварительный отбор.

Итог — удобный черновик из целевых 20–25 разнообразных изображений с источниками, а затем выбранный набор в Figma Design и секретной доске проекта в Pinterest.

- [Критерии пользовательского успеха](success-criteria.md).
