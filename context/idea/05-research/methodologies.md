# Методологии и устройство конвейера

## Рекомендуемый паттерн

Управляемый конвейер с сохранением состояния: интерпретация → подтверждение → получение кандидатов → нормализация источников → дедупликация → визуальная оценка → ручной выбор → два независимых экспорта.

Это инженерная рекомендация, выведенная из [рабочего сценария](../02-vision/day-in-the-life.md), а не утверждение, что готовый аналог реализует всю цепочку.

## Что подтверждают внешние материалы

- Pinterest различает Lens по внешней картинке и визуальный поиск по объекту существующего пина; входы нужно моделировать раздельно. Источники: [Lens](https://help.pinterest.com/en/article/pinterest-lens), [Visual search](https://help.pinterest.com/en/article/use-visual-search-features) (проверено 2026-11-02).
- Нативные related ideas и рекомендации доски — самостоятельные механизмы обнаружения. Они не доказывают единый мультиреференсный запрос. Источники: [Discover ideas](https://help.pinterest.com/en/article/discover-ideas-on-pinterest), [Boards](https://help.pinterest.com/en-gb/article/boards) (проверено 2026-11-02).
- Figma Plugin API создаёт отдельные image fills/узлы, но обычный плагин запускается пользователем в открытом файле. Нужен пользовательский шаг импорта. Источники: [Working with Images](https://developers.figma.com/docs/plugins/working-with-images/), [Plugins](https://developers.figma.com/docs/plugins/) (проверено 2026-11-02).

## Роль AI

Ограниченные структурированные операции: выделить смысл брифа, признаки примера и причины соответствия кандидатов. Планировщик, идентификаторы аккаунтов, секреты и экспорт не передаются в управление модели. Непрерывный автономный браузерный агент, ReAct-цикл и несколько постоянно работающих агентов для пилота не обоснованы.

## Практические следствия

У результата сохраняется происхождение: текстовый запрос, исходный pin ID, загруженный пример или рекомендация. Отбор и размещение разделены; промежуточный индекс позволяет повторить только упавший шаг. Выбор архитектора хранится как версия набора.
