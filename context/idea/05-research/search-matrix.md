# Матрица механизмов Pinterest

Дата проверки источников: 2026-11-02. Во всех строках runtime нашего приложения **не проверен**.

| Механизм | Вход | Подтверждение | Непроверенное | Критерий эксперимента |
|---|---|---|---|---|
| Текстовый поиск UI | Ключевые слова задания | [Официальная справка discovery](https://help.pinterest.com/en/article/discover-ideas-on-pinterest) | Практически доступный программный путь, персонализация и достаточная выдача | Получены реальные pin ID/URL и пригодные изображения по ландшафтному запросу |
| Официальный search/pins | Текст, аккаунт токена | [Search API](https://github.com/pinterest/pinterest-python-generated-api-client/blob/main/docs/SearchApi.md) | Он ограничен пользовательскими пинами и не доказывает широкий поиск | Явно зафиксирована область выдачи; свои сохранённые пины не представлены как глобальный discovery |
| Partner search | Поисковый term | [Search API](https://github.com/pinterest/pinterest-python-generated-api-client/blob/main/docs/SearchApi.md) | Beta, доступ не всем приложениям; Lens не описан этим контрактом | Проверен фактический доступ приложения и пригодность выдачи |
| Lens внешнего изображения | Загруженный пример | [Lens help](https://help.pinterest.com/en/article/pinterest-lens), [код search-by-image](https://github.com/dessant/search-by-image/blob/d5d20a64be2fc0fccdedbf52becb0a5f80a83848/src/utils/engines.js) | Доступность на нужном устройстве/аккаунте, допустимость интеграции, полнота и устойчивость | Картинка действительно используется как визуальный запрос; получены реальные источники и результаты |
| Visual search пина/фрагмента | Pin ID, изображение, область | [Справка](https://help.pinterest.com/en/article/use-visual-search-features), [py3-pinterest](https://github.com/bstoilov/py3-pinterest/blob/fdbe3bc64e2ec5bf0e58da01be364d81b6ce689d/py3pin/Pinterest.py) | Текущая работа кода, управление crop, текстовое уточнение для ландшафта | Проверены целый пин и выбранный объект; происхождение результата записано |
| Related ideas | Удачный существующий пин | [Справка](https://help.pinterest.com/en/article/discover-ideas-on-pinterest), [gallery-dl](https://github.com/mikf/gallery-dl/blob/382b1c717eb5d0b856d6b4c66fa9bce6573a3cf9/gallery_dl/extractor/pinterest.py) | Это отдельные рекомендации, не эквивалент Lens; качество/пагинация не проверены | Получены новые кандидаты от seed с сохранением связи и без повторов |
| Рекомендации доски | Уже сохранённые пользователем пины | [Boards help](https://help.pinterest.com/en-gb/article/boards) | UI, тип аккаунта и управляемость; нет подтверждённого публичного server API | Проверяется отдельно, без предварительного сохранения невыбранных кандидатов |

## Как читать результаты

Описание функции, реализация в чужом коде, успех одного запроса и рабочий сквозной пилот — четыре разных уровня доказательства. Протокол эксперимента должен содержать аккаунт без секретов, устройство/клиент, вход, результат, ID/ссылки, число уникальных кандидатов, время и ограничения.

По нескольким примерам не заявляется превосходство AI или Pinterest. Нативный механизм Pinterest остаётся приоритетом исследования; при провале результаты обсуждаются с пользователем, а не заменяются молча другим источником или способом.
