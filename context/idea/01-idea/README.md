# Идея

Помочь ландшафтному архитектору быстро получить редактируемый мудборд из Pinterest по короткому запросу и визуальным примерам.

## Контекст

Бюро занимается концепциями общественных пространств и частных садов. Архитекторам нужны примеры чужих работ для развития насмотренности, поиска решений и обсуждения пожеланий заказчика.

Основная потеря времени — поиск и отбор большого числа вариантов. Лента Pinterest дополнительно затягивает просмотр; архитектору трудно вовремя остановиться и перейти к проектированию.

Инструмент ограничивает поиск конкретной задачей и выдаёт конечную подборку. Примеры запросов из интервью: «МАФы», «китайский сад», «азиатский сад», «бионические формы», «искривления». Полный формализованный бриф не обязателен.
