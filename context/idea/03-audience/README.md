# Аудитория

Внутренние пользователи ландшафтного бюро, которые разрабатывают концепции общественных пространств и частных садов. Им требуются референсы чужих работ под тему, конкретный элемент, пожелания заказчика или визуальный пример.

Первый пользователь и основной эксперт пилота — главный архитектор, от которой пришла идея. Пользователь чата организует техническую разработку и первые проверки на своём ПК и Pinterest-аккаунте.
