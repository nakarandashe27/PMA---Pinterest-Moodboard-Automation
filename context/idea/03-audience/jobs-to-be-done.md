# Задачи, ради которых используют инструмент

| Ситуация и боль | Требуемое поведение | Польза |
|---|---|---|
| Нужно найти варианты МАФа, формы или стилевого решения | Принять короткий запрос, показать интерпретацию и выполнить ограниченный поиск Pinterest | Меньше времени на поисковые итерации |
| Нравится отдельный признак картинки заказчика | Учесть пояснение к примеру; исследовать нативный визуальный поиск Pinterest | Подборка соответствует нужному признаку |
| Лента затягивает бесконечным просмотром | Выдать конечный черновик вместо бесконечной ленты | Можно перейти к проектированию |
| В подборке несколько неудачных изображений | Заменить только отмеченные с учётом причины | Не приходится пересматривать всё |
| Изображения нужно использовать в концепции | Разместить выбранное отдельными объектами в Figma Design и сохранить источники | Удобно компоновать и дополнять |
| Требуется вернуться к проектным находкам | Сохранить выбранные существующие пины в секретную доску проекта | Источники остаются доступны в Pinterest |

См. [сценарий](../02-vision/day-in-the-life.md), [границы первой версии](../04-mvp/scope.md).
