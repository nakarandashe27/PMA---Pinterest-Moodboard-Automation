# Бизнес-контекст проекта

**PINTEREST MOODBOARD AUTO** — внутренний инструмент ландшафтного бюро для подготовки Pinterest-референсов и продолжения работы в Figma Design.

Дата: 2026-11-02. Подтверждённая ценность — экономия времени/внимания. Коммерческие продажи, тарифы и рекламная воронка не согласованы. Неизвестные данные явно оставлены для заполнения.
