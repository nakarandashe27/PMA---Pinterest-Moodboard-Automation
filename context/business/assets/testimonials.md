# Отзывы и кейсы

Реальных отзывов, измеренных кейсов и подтверждённых результатов пилота пока нет. Собрать после самостоятельного использования главного архитектора.

Для кейса фиксировать задачу без конфиденциальных материалов, исходное/новое время, число пригодных кандидатов, замены, экспорт и ограничения. Численные ориентиры интервью не публиковать как достигнутый эффект.

Цитаты использовать только с согласия автора. Вымышленные отзывы не добавлять.

См. [пилот](../../idea/04-mvp/success-metrics.md), [показатели](../goals/kpi.md), [оформление](brand-guidelines.md).
