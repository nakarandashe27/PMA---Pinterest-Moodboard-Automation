# Путь внутреннего пользователя

Идея главного архитектора → согласование задачи с техническим инициатором → проверка интеграций → установка на её ПК → подключение своего аккаунта → первое совместно проверенное задание → самостоятельный пилот → обратная связь и улучшение.

Путь конкретной подборки: ввод → интерпретация → подтверждение → конечная сетка → выбор/замены → сохранение пинов и импорт Figma → работа над концепцией.

Продажи, покупки подписки, рекламные касания и внешний онбординг не входят в подтверждённый путь. Использование после пилота и частота повторных запросов **[заполнить позже]**.
