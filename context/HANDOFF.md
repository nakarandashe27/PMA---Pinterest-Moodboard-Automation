## Дополнение 2026-11-13: AI через подписку ChatGPT (Codex)

**По поручению пользователя** (архитектору не подошёл API-ключ, есть подписка ChatGPT): в desktop второй режим AI — [ADR 0013](architecture/06-решения/журнал-решений/2026-11-13-ai-через-подписку-codex.md). «Настройки AI»: выбор «Подписка ChatGPT (Codex)» / «Свой API-ключ» (по умолчанию API), без перехода между ними. PMA находит нативный `codex.exe` без Node: официальный установщик (`%LOCALAPPDATA%\Programs\OpenAI\Codex\bin`) → npm-пакет `codex-win32-*` → PATH. **Приложение Codex из Microsoft Store как runtime не годится**: его `codex.exe` в `WindowsApps` другим программам запускать нельзя (проверено: Access is denied), но вход в нём общий (`%USERPROFILE%\.codex`), поэтому архитектору нужна ещё одна команда установщика CLI. Вход — сам человек (приложение Codex или кнопка `codex login`); `login status` только классифицируется (при API-ключе он печатает маску ключа). «Проверить» — один `codex exec` с картинкой 64×64; до проверки AI-шаги закрыты. Денег нет, слот пула ≤100 резервируется в ledger до вызова. Тот же исполнитель `server/codex-selection.mjs`, теперь с командой запуска. Код: `server/ai-codex.mjs`, маршруты `/api/ai/mode`, `/api/ai/codex/{probe,login}`; тесты `server/test/ai-codex.test.mjs` на подменном codex; смоук +1 проверка (Codex не найден → понятная причина), `PMA_TEST_CODEX=none`. Методичка: слайд AI ведёт через подписку, API-ключ — альтернатива.

**Живая проверка 2026-11-13 (с разрешения пользователя, 2 вызова):** собранный `release/win-unpacked/PMA.exe` 0.1.2, временные данные, PATH без Node. ## Итог архитектурной сессии 2026-11-06

**Выполнено только проектирование и документация:** [ADR 0011](architecture/06-решения/журнал-решений/2026-11-06-десктопное-приложение.md), [desktop-контракт](architecture/05-стек/десктопное-приложение.md), [первый запуск](architecture/04-потоки/первый-запуск-десктопа.md), [приёмка](architecture/06-решения/приёмка-десктопа.md) и [premortem](architecture/07-нефункциональные/риски-десктопа.md). Изолированный субагент проверил предложение и отдельно IPC-уточнение; меры включены в целевые документы.

- Electron + backend utilityProcess, сохранение React и доменного Node/SQLite/Playwright. Только упакованный app://pma UI, ограниченный preload IPC, MessagePort main↔worker; обычные UI API/media не публикуются на localhost. Figma-only bridge остаётся 127.0.0.1:8787 с ограниченным pairing.
- У архитектора нет ChatGPT-подписки. Первый релиз — API со своими endpoint/model/key, без списка брендов; реальные capabilities/usage/billing mapping проверяются. Бюджет/тариф задаёт владелец; до настройки платный AI off. Общий предел пилота до 100/месяц Europe/Moscow, денежный резерв до вызова, ledger не откатывается при restore. Legacy Codex-код сохраняется, обязательной зависимостью API-пилота не является.
- Обычный установщик, админ-права доступны; установленный Chrome с отдельным PMA-профилем. Крестик завершает процессы/операции с сохранением unknown, ручное продолжение. Обновления вручную новым installer, данные сохраняются, backup перед schema migration. Разовая совместная настройка API/бюджета/Figma допустима, затем архитектор работает сама.
- Данные вне установки в %LOCALAPPDATA%/PMA, OS-bound секреты, чистый дистрибутив. Перенос текущих проектов/авторизаций не согласован как автоматическое действие. Нет autoTTL, пользовательское удаление ещё не реализовано; uninstall сохраняет данные.
- ОС архитектора предположительно Windows 10, build/arch ещё не проверены. На текущем ПК read-only .NET показал Windows 10.0.19045/X64; это не подтверждение её ПК. Upstream Playwright указывает Windows11+, поэтому Win10 только отдельная проверяемая конфигурация. Подпись/доверенная передача и рабочая сеть/API/Figma остаются выпускными gates.
- Реализация оболочки, установщика, API-адаптера и миграции кода не начата. Ключи не создавались; сервис, браузеры, профили и завершённые экспорты в этой сессии не запускались и не менялись. 141 тест/build остаются последним ранее зафиксированным результатом.
- Проверка контекста: в 21 новом/обновлённом документе проверены 407 локальных Markdown-ссылок и используемые фрагменты, ошибок не найдено. Сравнение SHA-256 подтвердило неизменность 100 защищённых файлов кода/прежних ADR/протоколов/business. Обновления существующих файлов выполнены адресным merge, без полной перезаписи; новые desktop-гейты и G2/G3 остаются открытыми.

**Следующее действие после отдельного поручения на реализацию:** этап 8D.1 [roadmap](architecture/08-дорожная-карта/roadmap.md) — квалификация минимального установленного runtime. ## Суть продукта и закреплённые решения

Внутренний инструмент ландшафтного бюро сокращает время поиска и отбора референсов. Веб-задание содержит текст, фото и пояснение, что в фото важно. Pinterest — единственный источник. Черновик ориентирован на 20–25 разнообразных изображений; недобор допускается. Окончательный выбор остаётся за архитектором, ссылки на источники сохраняются. Требования и ответы пользователя: [scope](idea/04-mvp/scope.md), [Q1–Q29](idea/04-mvp/decisions.md).

- Поиск выполняется через отдельный профиль Chrome/Playwright с ручным входом владельца. Видимые проверки Pinterest останавливают автоматизацию; пользователь проходит их сам. Не подменять неработающий Lens текстовым поиском молча.
- Необязательный AI-отбор работает через Codex CLI со штатным входом через ChatGPT по выбору пользователя. Отдельный API-ключ не требуется. Модель оценивает предоставленные изображения без браузерных инструментов и авторизации; поиск/экспорт выполняет сервис. Это расход квоты подписки с конечными локальными пределами, а не безлимитный API.
- Один зафиксированный ручной выбор идёт в оба назначения: секретную Pinterest-доску проекта и отдельный именованный фрейм Figma Design. Статусы независимы. Native-плагин запускается явно; существующие фреймы и ручная работа сохраняются.
- Сначала разработка и проверка на ПК пользователя, затем пилот на ПК главного архитектора. Общий сервер компании — отдельный этап после пилота. Удобство и качество отборов ещё должна оценить архитектор; двукратная экономия времени — ориентир, не измеренный результат.

## Технические нюансы, которые нельзя потерять

- Pinterest ограничивает имя доски 50 символами. Генератор учитывает лимит и суффикс проекта. Создание доски из Save уже сохраняет первый пин: второй Save для него не нужен.
- Pinterest может выдать другой savedPinId. Квитанции различают исходный и сохранённый ID; сопоставление изображения не требует их равенства. Неполная/устаревшая выдача допускает ограниченные повторные чтения, без повторения сохранения.
- После таймаута/перезапуска результат записи unknown сначала сверяется. Неизвестный отсутствующий пин не записывается повторно автоматически. Ручное удаление/правка не означает разрешение восстановить объект молча.
- UI sandbox Figma не предоставил `crypto.subtle`. Проверка исходных байтов теперь использует переносимую SHA-256, проверенную по стандартным векторам и Node crypto; контроль SHA сохранён до WebP→PNG-преобразования.
- Проверка `event.source === parent` отбрасывала ответы Figma и приводила к таймауту. Обмен UI/native теперь использует channel экземпляра UI и requestId; прямые/пересланные/synthetic ответы и посторонний channel проверены тестами.
- Исходники плагина: [build-frame](../spikes/figma-g1/build-frame.mjs), [managed importer](../spikes/figma-g1/import-managed.mjs), [handler](../spikes/figma-g1/plugin/handler.js), [UI template](../spikes/figma-g1/plugin/ui.template.html), [SHA-256](../spikes/figma-g1/sha256.mjs). После изменения выполнить `node scripts/build-plugin.mjs`. `plugin/code.js` и `plugin/ui.html` сгенерированы.
- Manifest уже импортирован в Figma Desktop. После изменения исходников закрыть и заново запустить плагин; повторный импорт manifest не нужен. Плагин использует dev-origin `http://localhost:8787`, сервис слушает loopback 127.0.0.1. Прежняя запись `http://127.0.0.1:8787` в devAllowedDomains вызывала ошибку валидатора Figma.
- Код подключения действует 15 минут и открывает одну попытку/снимок. Обновление кода для того же набора не создаёт новый фрейм. Старые коды из чата переносить не нужно. UI: «Экспорт выбранного» → «Код подключения Figma» → «Обновить код этого набора».
- Native document marker не является глобально достоверным fileKey и может копироваться с документом. Приватный Plugin API не включён. Это открытое ограничение для G2.
- В этой сессии Computer Use читал native accessibility, но клики и захват Figma часто завершались ошибками. Пользователь вручную нажимал кнопки; результат проверен через сервис, readback и screenshot коннектора. В новом чате доступность инструментов проверить заново; не подменять native-доказательство коннекторным созданием.
