Подключить Pinterest

1

Откройте PMA → Открыть своё подключение

2

Название — любое. Придумайте пароль PMAОт 12 символов. Это не пароль Pinterest — запишите его, сбросить самим нельзя.

3

Создать подключениеОткроется отдельное окно Chrome с Pinterest.

4

Войдите в Pinterest в этом окне → Я вошёл — проверить

Ваш обычный Chrome PMA не трогает — у неё свой, отдельный.

Подключить Figma

1

В PMA слева внизу Состояние PMA → Открыть папку плагина

2

Откройте Figma — программу, не сайт — и любой файл Design

3

Plugins → Development → Import plugin from manifestВыберите manifest.json из открытой папки.

Плагин работает, только пока PMA открыта. Нет пункта Development — это запрет в организации, напишите нам.

Подключить AI

1

Ключ — platform.deepseek.com → API keysПополните счёт на пару долларов.

2

Настройки AI → значения из таблицы

3

Сохранить профиль → ключ → Сохранить ключ → Платная проверкаПроверка стоит доли цента.

Без AI всё работает. С AI PMA сама делает запрос из замысла и подсказывает лучшие кадры. Больше вашего предела не потратит.
