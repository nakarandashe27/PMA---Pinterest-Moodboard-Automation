Подключить Pinterest

⏱ 5 минут
1

Откройте PMA → Открыть своё подключение

2

Название — любое.
Придумайте пароль PMA 🔒От 12 символов. Это не пароль от Pinterest. Запишите его: сбросить самим нельзя.

3

4

Так выглядит создание подключения
✅Готово, когда слева внизу видно ваше имя с зелёной точкой
💡Ваш обычный Chrome PMA не трогает — у неё свой отдельный.

Что-то не так?

Почти всё чинится, ничего не пропадает
📌 Pinterest просит войти
Открыть Pinterest → войти → Продолжить поиск
⏸ Поиск прервался или PMA закрыли
Нажмите Продолжить поиск. Найденное сохранено
🎨 Плагин: «другой версии»
Закройте окно плагина в Figma и откройте заново
🎨 Нет кода Figma / «порт занят»
Закройте лишние копии PMA и запустите PMA заново
✨ AI закрыт
Настройки AI → Платная проверка. Без AI PMA тоже работает
🔒 Забыли пароль PMA
Самим не сбросить — напишите нам
✉️Не помогло? Состояние PMA → Создать отчёт для помощи и пришлите нам файл вместе со скриншотом. В отчёте нет ваших проектов, картинок и паролей.
📁Ваши проекты хранятся отдельно от программы. Обновление и удаление PMA их не трогают.
