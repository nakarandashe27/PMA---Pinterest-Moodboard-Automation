# Рабочий экран PMA

Концепт: pma-workspace-concept.png. Создан встроенным Image Gen 2026-11-03; используется как визуальная спецификация, не как источник референсов. Финальный интерфейс использует реальные локальные Pinterest-изображения G1 и новые результаты поиска.

Направление: светлая архитектурная рабочая среда, sidebar 242 px при viewport 1488×1058, контент с отступом 34 px. Фон #f7f8f5, панели #ffffff, текст/primary #263f32, secondary #788071, border #dee3db, selected #d8e9b5. Радиус 8–12 px, без крупных теней и градиентов. Inter: заголовок 40–44 px/600–700, body и кнопки 14–16 px, подписи 12–14 px.

Компоненты: Sidebar, ProjectHeader, BriefSummary/BriefEditor, CollectionToolbar, ReferenceGrid/ReferenceCard, SelectionBar, ConnectionDialog, ExportDialog. Иконки — единая тонкая outline-система. Фото содержат object-fit: contain; источники открываются отдельными ссылками. Основные состояния: реальная подборка G1, редактирование задания, вход Pinterest, поиск/отмена, ручной выбор, подготовка Figma. На узком экране sidebar становится верхней панелью, сетка уменьшается до двух/одного столбца; footer не перекрывает карточки.

Тексты primary-экрана: PMA; Проекты; Пробная подборка G1; Подборки; Pinterest; Не подключён; Подключить; Сохранено на этом ПК; Бионические скамьи; Техническая подборка · 2 ноября; Новое задание; Задание; Изменить; Все; Выбранные; Снять выбор; Референс; Открыть пин; Выбрано; Сохранить выбор; Подготовить Figma. Числа зависят от реальных данных. Формы и сообщения об ошибках дополняют эту систему по согласованным требованиям.

Умышленное отличие от концепта: изображения в приложении — настоящие источники Pinterest, а не иллюстрации Image Gen. Текст задания берётся из сохранённого запроса, без выдуманного брифа заказчика. Состояние подключения устанавливается по реальному браузерному профилю.
